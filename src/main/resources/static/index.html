WHAT YOU GET

Everything a secure record exchange needs

Built directly from the project DFD — each feature maps to a real, working endpoint.

🛡️

Consent-gated access

Doctors can only read or add records after the patient approves. Enforced on the server, not just hidden in the UI.

🧬

FHIR R5 bundles

Records are mapped to Condition, Observation, MedicationRequest, Procedure, DiagnosticReport, Immunization and AllergyIntolerance.

🧾

Complete audit trail

Logins, requests, consent decisions, record changes and FHIR generation are all written to audit logs.

🔐

One-time profile lock

Patient personal info locks after first submission; a doctor can authorize one controlled unlock.

📑

PDF health reports

Download a consent-checked PDF summary of a patient's records in one click.

📊

Admin analytics

Live stats, data distribution, user lock/activate controls and full audit log viewer.
